# The Blackwood Interrogations

A 20-minute ESL grammar lesson on **indirect questions and the backshift of tenses**, delivered as an interactive murder mystery set in 1932.

**Series:** Reported Speech  
**Target structure:** Indirect questions (yes/no and wh-) with tense backshift  
**Level:** Intermediate – Upper Intermediate  
**Format:** Single HTML file, no dependencies, works offline

---

## The Premise

Lord Reginald Blackwood has been found dead in the library of Blackwood Manor. Poisoned tea. Three suspects. One detective.

Students play the role of Detective Inspector Voss's assistant. Their job: report her questions accurately to the Chief Inspector, who was not present during the interrogations. Every grammatical error lets the killer walk free.

---

## Structure

| Phase | Content | Time |
|---|---|---|
| 01 — The Scene | Setup, stakes, recall of tense backshift | 3 min |
| 02 — The Rules | Yes/no vs wh- questions, backshift table, 4 common errors | 5 min |
| 03 — Interrogation | Three fill-in exercises (one per suspect) + error correction | 5 min |
| 04 — The Briefing | 5 dramatic scenarios, oral production task | 5 min |
| 05 — Verdict | 3-rule summary, exit ticket (4 questions, no hints) | 2 min |

---

## Grammar Coverage

- Indirect yes/no questions using *if* / *whether*
- Indirect wh- questions (who, what, where, when, why, how, how long)
- Backshift: Present Simple → Past Simple, Past Simple → Past Perfect, Present Perfect → Past Perfect, Present Continuous → Past Continuous, *will* → *would*, *can* → *could*
- Statement word order in indirect questions (no inversion)
- The 4 fatal errors: inversion, question mark, missing connector, forgotten backshift

---

## Usage

Open `index.html` in any browser. No build step, no server required.

Navigate between phases using the tab bar at the top of the page. Each phase is self-contained. The lesson is designed to be teacher-led but can also be used independently.

---

## Interactive Elements

- **Phase 03:** Fill-in-the-blank exercises with instant feedback (correct/incorrect per field)
- **Phase 04:** Click-through scenario cards with hidden model answers
- **Phase 05:** Exit ticket — students produce full indirect questions aloud with no scaffolding
